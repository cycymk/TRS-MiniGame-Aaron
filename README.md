# TRS MiniGame

## 專案概況

TRS MiniGame 是一款瀏覽器 Canvas 太空動作小遊戲，主要由 `index.html`、`src/game.js`、`src/runLogic.js`、`src/gameLogic.js` 與樣式檔組成，測試集中在 `tests/`。核心玩法分為 CHRONO RUN 跑酷與 CHRONO BOSS 戰鬥：玩家操控飛船閃避紅色危險物、拾取黃色/青色道具、使用射擊與 Hack 小遊戲取得破盾、加速或清場優勢。功能包含手機觸控、陀螺儀微視角、動態隧道背景、排行榜、結算畫面、AUTO FIRE 與 FPS 顯示。近期更新降低 CHRONO RUN 難度，重做敵我/道具辨識、受擊與爆炸效果，優化背景效能，並修正道具拾取、開場生成、結算捲動與自動射擊狀態。
